# Reiso Studio — Build Plans Overview
Source: `Reiso_Studio_Website_Content.pdf` (in Downloads).

Pages: Home, About, Products, Services, Templates, Work, Blog, Contact.
Design language: Framer-style — dark bg `#050508`, glass nav, gradient orbs, grid backdrop, reveal-on-scroll, stagger cards, marquee strip, magnetic buttons.

Workflow: user shares how each page should look (screenshot/reference/description) → build page on top of `frontend/css/*` tokens. Do not hard-code colors outside `variables.css`. Responsive overrides only in `frontend/responsive/*`.
